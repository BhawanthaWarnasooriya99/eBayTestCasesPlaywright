# eBayTestCasesPlaywright

This repository contains Playwright tests (written in TypeScript) to verify the behavior of the **"Best Seller / Related Products"** feature on an eBay-like shopping website. The tests cover both functional and edge-case scenarios relevant for QA assessments.

Some test cases are combined and covered within a single test script to improve execution efficiency and reduce redundancy.
---

## Getting Started

### 1. Clone the Repository

git clone https://github.com/<your-username>/eBayTestCasesPlaywright.git
cd eBayTestCasesPlaywright

### 2. Install  Dependacies

npm install

### 3. Run the Tests

npx playwright test


### Tech Stack
Playwright – UI automation framework

TypeScript – for type-safe scripting
